# Scribe Documentation

This directory contains documentation for the Scribe app.

## Contents

- [Collections](collections.md) - How Scribe groups blocks into collections
- [Indexing System](indexing.md) - How Scribe indexes documents for search and navigation
- [Slug System](slugs.md) - How Scribe generates and manages document slugs
- [Linking System](linking.md) - How Scribe handles internal document linking
- [Local Layout](fs.md) - How Scribe maps streams to the local filesystem

## Overview

Scribe is a Tributary app for editing, indexing, and cross-linking documents. The documentation in this directory explains how the various components work.
