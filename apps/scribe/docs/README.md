# Scribe Documentation

This directory contains documentation for the Scribe app.

## Contents

- [Collections](collections.md) - How Scribe groups notes into collections
- [Indexing System](indexing.md) - How Scribe indexes notes for search and navigation
- [Slug System](slugs.md) - How Scribe generates and manages note slugs
- [Linking System](linking.md) - How Scribe handles internal note linking
- [Local Layout](fs.md) - How Scribe maps libraries to the local filesystem

## Overview

Scribe is a Tributary app for editing, indexing, and cross-linking notes. The documentation in this directory explains how the various components work.
